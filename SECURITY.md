# Security and diagnostic privacy

Do not post credentials, full process dumps, vendor model assets, personal recordings or unreviewed diagnostic archives in public issues. Diagnostic exports are local and require user action to share. They may still contain game titles, module names and some paths.

For a sensitive vulnerability, first contact the maintainer without disclosing exploit details in a public issue. This preview has no guaranteed response or patch SLA.

Model files and manifests should come from a source you are authorized to use and trust. Integrity hashes are not a rights grant. The client does not require administrator privileges and does not change drivers, registry recovery settings or security protections.
